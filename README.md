# rebit · 토끼 챗봇 레비

가상의 리빙 셀렉트숍 **rebit** 메인 화면과, 우측 하단 퀵메뉴에 붙은 토끼 챗봇 **레비**입니다.
IBES-NET의 파이 1:1 대화 기능을 떼어 내 쇼핑몰 고객센터용으로 다시 만들었습니다.

## 실행

Node.js 24가 필요합니다. 외부 패키지가 없어 `npm install`은 필요 없습니다.

```
npm start     # http://127.0.0.1:3100 (쇼핑몰), /admin (운영자 화면)
npm test      # 자동 테스트
```

처음 실행하면 운영자 계정 `admin`과 임시 비밀번호가 콘솔에 **한 번만** 출력됩니다. 로그인 후 [계정] 메뉴에서 바꿔 주세요.
비밀번호를 잊었거나 계정을 더 만들 때는 `npm run admin -- <아이디> [이름]`을 실행하면 새 임시 비밀번호가 나옵니다.
처음부터 정한 값으로 만들고 싶으면 첫 실행 전에 환경변수 `ADMIN_ID`, `ADMIN_PASSWORD`를 넣어 두면 됩니다.

## 손님 화면 (레비)

- 오른쪽 아래 퀵메뉴: **레비 상담** · 장바구니 · TOP
- 레비 창을 열면 인사말과 함께 **저장된 답변 카드**가 가로로 나옵니다. 분류 버튼으로 거르고 **[답변보기]**를 누르면 레비가 바로 답합니다.
- 입력창에 직접 질문하면 레비가 키워드로 맞는 답변 카드를 찾아 줍니다. 못 찾으면 상담 연결을 권합니다.
- 입력창 아래 **[상담 연결]**을 누르면 운영자와 1:1 대화가 시작되고, 레비가 답을 못 찾았던 질문은 상담원에게 자동으로 넘어갑니다. 연결 중에는 버튼이 **[상담 종료]**로 바뀝니다.
- 운영자가 상담 화면을 열어 두지 않았으면 부재 안내와 운영 시간을 보여 주고, 메시지는 남겨 둡니다.
- 운영자 답장은 실시간으로 도착하고, 창을 닫아 두었으면 퀵메뉴에 숫자 배지와 말풍선 알림이 뜹니다.
- 주소 끝에 `#levi`를 붙이면 레비 창이 열린 채로 시작합니다.

손님은 가입 없이 브라우저 쿠키로만 구분되며, 운영자 화면에는 `손님 0001`처럼 번호로 표시됩니다.

## 운영자 화면 (`/admin`)

| 메뉴 | 하는 일 |
|---|---|
| 상담 | 진행 중·종료 상담 목록, 레비 이름으로 답장, 토끼 이모티콘 7종, **저장된 답변 넣기**(검색해서 입력창에 붙인 뒤 고쳐 보내기), 상담 종료 |
| 저장된 답변 | 손님에게 보이는 질문 카드 추가·수정·삭제·순서 변경·숨기기, 키워드 설정, 조회 수, 카드 미리보기 |
| 안내 문구 | 첫 인사, 상담원 부재 안내, 운영 시간, 답변 없는 상담 자동 종료 시간(기본 5분 뒤 안내 · 10분 뒤 종료, 0이면 끔) |
| 계정 | 내 비밀번호 변경, 운영자 추가·삭제·이름 변경, 운영자별 상담 수 (이름은 운영 화면에만 보이고 손님에게는 모두 레비) |

## 서버 없이 올리기 (카페24 스킨 등)

```
CONTACT_URL=/board/consult/list.html node tools/build-static.mjs dist/cafe24
```

CSS·JS를 모두 넣은 `index.html` 한 파일이 나옵니다. 저장된 답변 카드, 키워드 찾기, 퀵메뉴는 그대로 동작합니다.
실시간 상담은 서버가 필요해서, 이 버전의 **[상담 연결]**은 `CONTACT_URL`(1:1 문의 게시판 등)로 안내합니다.
답변 내용은 `server/seed.js`에서 고친 뒤 다시 빌드하면 됩니다.

## 공개 서버에 올릴 때

계속 켜져 있는 Node 서버와 파일이 유지되는 디스크가 필요합니다(카페24 일반 호스팅, Vercel에서는 실시간 상담이 동작하지 않습니다).

- `NODE_ENV=production`: HTTPS 전용 쿠키를 켭니다. HTTPS 없이는 운영자 로그인이 되지 않습니다.
- `HOST=0.0.0.0`, `PORT`: 서버 주소
- `TRUST_PROXY=1`: 프록시 뒤에서 손님 IP를 읽을 때
- `REBIT_DATA_DIR`: DB 저장 위치 (기본 `data/`). 이 폴더를 정기적으로 백업하고 저장소에 올리지 마세요.
- 프록시를 쓴다면 `/api/levi/stream`, `/api/admin/stream` 응답을 버퍼링하지 않도록 설정해 주세요.
